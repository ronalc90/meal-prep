MealPrep

Planifica tus comidas semanales y genera listas de compras automaticas. Ahorra tiempo y dinero.

Ver en GitHub API Docs

Caracteristicas

Gestion de Recetas

Crea, edita y busca recetas con ingredientes detallados, tiempos de preparacion y calorias por porcion.

Planificacion Semanal

Calendario interactivo de 7 dias con 4 comidas diarias: desayuno, almuerzo, cena y snack.

Lista de Compras Inteligente

Generacion automatica que agrega ingredientes, convierte unidades y agrupa por pasillo del supermercado.

Auto-generacion

Rellena automaticamente el plan semanal basado en tus preferencias y limite calorico diario.

Dashboard

Estadisticas semanales con calorias totales, progreso de compras y tus recetas mas utilizadas.

Exportar

Exporta tu lista de compras como texto plano para compartir o imprimir facilmente.

Algoritmo de Lista de Compras

Recolectar
→
Escalar
→
Normalizar
→
Agregar
→
Formatear
→
Agrupar

El motor convierte unidades a una base comun (ml para volumen, g para peso), suma cantidades del mismo ingrediente, formatea a unidades practicas y organiza todo por pasillo del supermercado.
