Planifica tus comidas semanales, genera listas de compras automaticas y ahorra tiempo y dinero.

Funcionalidades

📅

Planificador Semanal

Calendario de 7 dias con 4 comidas diarias: desayuno, almuerzo, merienda y cena.

📖

Base de Recetas

Crea y gestiona tus recetas con ingredientes, tiempos de preparacion y calorias.

🛒

Lista de Compras

Generada automaticamente desde tu plan semanal con agregacion inteligente.

⚖️

Conversion de Unidades

Sistema integrado que unifica cantidades para simplificar tus compras.

💰

Control de Presupuesto

Seguimiento del gasto semanal en alimentacion para optimizar tu economia.

📊

Dashboard

Estadisticas y metricas para visualizar tus habitos de planificacion.
